# 001 — 用可核对的运行记录重建 TDFC

2026-09-10，用户授权大幅重构；范围和思维/阵营规则已通过 grilling 确认。

旧版信息、生存、小队控制器分别写入同一单位，动作相互覆盖，日志只能说明进入分支。新结构用一个战术时钟、单位记录和动作执行入口，暂停、换图、错误显式处理，界面读取实际使用的记录。

决策模块只收普通对象和候选地形，不依赖游戏类型；真实 AS3 逻辑测试可直接执行。移动指令另行核对位置是否改善，压制另行观察弹药/发射计数，避免用“调用开火”冒充效果。

思维等级和文化风格分开：前者影响判断速度、信息时效、掩体比较和协同，后者决定推进/火力偏好。精英数字不充当线性等级。敌我关系使用当前 fraction，在延迟报告到达时重新检查。

旧控制器从 src 移除，历史保留在 git 的 4201b3c 及更早提交。只保留当前消费的配置，避免无效开关让维护者误以为功能已接入。

测试先保证完整存档和依赖：复制当前用户槽位，通过 `newGame(99)` 导入并核验角色/等级/原版恢复地点；所有行为只在精确测试身份且有场景配置时驱动。技能武器依赖的竞争自动测试仅在 TDFC 的测试副本关闭。

取舍：掩体采用短程几何检查和动作反馈，当前不做复杂全图寻路；特殊头目交回原版。这些边界在 UI 与说明中保留，不伪装为全兵种战术覆盖。
